LANStream v0.4.0 Linux/Docker update
======================================

IMPORTANT CONFIG MOVE
---------------------
The old file:

/home/chip/Projects/LANStream/config/paths.txt

is replaced by:

/home/chip/Projects/LANStream/config.txt

Before replacing the source, copy your existing path/profile lines into the new
config.txt.

The config subdirectory is no longer used.

Example config.txt:

port=8060
use_master_password=false
master_password=
transcoder=auto

/mnt/media/Movies
/mnt/media/TV

Docker notes
------------
The updated LEC preset bind-mounts:

/home/chip/Projects/LANStream/config.txt -> /config.txt

and overrides LANStream's internal port to 8080. The LEC host-port choice still
controls the LAN-facing Docker port.

The cache remains:

/home/chip/Projects/LANStream/cache

Transcoding
-----------
Linux now tries VAAPI first and automatically falls back to software libx264 if
VAAPI is unavailable.

Check:

http://SERVER-IP:PORT/transcoder-status

Windows
-------
See README-WINDOWS.txt and build_windows.bat.

No database or installation service is required for the Windows build.
